# 🇷🇺 Российские приложения, которые не работают с VPN

Автоматически обновляемый список российских сайтов и приложений, которые
блокируют доступ при включённом VPN. Данные собираются из открытых источников
раз в сутки через GitHub Actions.

> Этот файл регенерируется автоматически. Не редактируйте его вручную —
> правки будут потеряны. Для изменений правьте `scraper/aliases.yaml` и
> `scraper/sources.yaml`.

## Быстрый старт

См. [`scraper/README.md`](scraper/README.md) для инструкций по локальному
запуску, добавлению источников и кастомизации.

## Машиночитаемые данные

[`data/apps.json`](data/apps.json) — полный список в JSON.
